# PLAN DE PROYECTO: SISTEMA DE GESTIÓN PARA TALLER MECÁNICO
=====================================================================

## DESCRIPCIÓN GENERAL
Aplicación web para gestionar las operaciones de un taller mecánico:
clientes, vehículos, órdenes de trabajo, inventario, y facturación.

=====================================================================
## MÓDULOS DEL SISTEMA
=====================================================================

### 1. GESTIÓN DE CLIENTES
- Registro de clientes (nombre, teléfono, correo, dirección)
- Historial de visitas y servicios por cliente
- Búsqueda y filtrado de clientes

### 2. GESTIÓN DE VEHÍCULOS
- Registro de vehículos (placa, marca, modelo, año, color, VIN)
- Asociación de vehículo a cliente
- Historial de servicios por vehículo

### 3. ÓRDENES DE TRABAJO (OT)
- Creación de OT al recibir un vehículo
- Descripción del problema reportado por el cliente
- Asignación de mecánico responsable
- Lista de trabajos realizados y repuestos utilizados
- Estados: Recibido → En diagnóstico → En reparación → Listo → Entregado
- Fecha de ingreso y fecha estimada de entrega

### 4. INVENTARIO DE REPUESTOS
- Catálogo de piezas y repuestos (código, nombre, descripción, precio costo, precio venta)
- Control de stock (cantidad disponible, stock mínimo con alerta)
- Registro de entradas y salidas de inventario
- Proveedores de repuestos

### 5. FACTURACIÓN
- Generación de facturas a partir de la OT
- Desglose de mano de obra y repuestos
- Cálculo automático de totales e impuestos
- Historial de pagos (efectivo, transferencia, tarjeta)
- Impresión / exportación a PDF

### 6. GESTIÓN DE MECÁNICOS / EMPLEADOS
- Registro de empleados (nombre, especialidad, contacto)
- Asignación de OT por mecánico
- Reporte de carga de trabajo

### 7. REPORTES Y DASHBOARD
- Ingresos del día / semana / mes
- OT abiertas vs. cerradas
- Repuestos más utilizados
- Clientes más frecuentes
- Gráficas y métricas clave

### 8. AUTENTICACIÓN Y ROLES
- Login con usuario y contraseña
- Roles: Administrador, Recepcionista, Mecánico
- Control de acceso por módulo según rol

=====================================================================
## STACK TECNOLÓGICO PROPUESTO
=====================================================================

### Frontend
- React + TypeScript
- Tailwind CSS (UI)
- React Router (navegación)
- React Query / Zustand (estado)

### Backend
- Node.js + Express (API REST)
  -- ó --
- Django (Python) si se prefiere un framework más completo

### Base de Datos
- PostgreSQL (relacional, ideal para este tipo de negocio)
- ORM: Prisma (Node) o Django ORM

### Autenticación
- JWT (JSON Web Tokens)

### Extras
- jsPDF / React-PDF (generación de facturas en PDF)
- Docker (contenedorización para despliegue)

## ESQUEMA DE BASE DE DATOS (ENTIDADES PRINCIPALES)
=====================================================================

clientes         → id, nombre, telefono, correo, direccion, created_at
vehiculos        → id, cliente_id, placa, marca, modelo, anio, color, vin
empleados        → id, nombre, especialidad, telefono, rol
ordenes_trabajo  → id, vehiculo_id, empleado_id, descripcion_problema,
                   estado, fecha_ingreso, fecha_entrega_est, fecha_entrega_real
ot_servicios     → id, orden_id, descripcion, costo_mano_obra
repuestos        → id, codigo, nombre, descripcion, precio_costo, precio_venta, stock
ot_repuestos     → id, orden_id, repuesto_id, cantidad, precio_unitario
facturas         → id, orden_id, subtotal, impuesto, total, metodo_pago, fecha
proveedores      → id, nombre, telefono, correo
